# Sample assets

Placeholders so every example composition renders on a fresh install. All three were made for this template
(ffmpeg test sources and a hand-written SVG) and carry no third-party rights. Replace them with the product's own
material before building a real ad.

| File | Stands in for |
|---|---|
| `illustration.svg` | A text-free editorial illustration of the news scene (generated or drawn) |
| `paper-sheet.jpg` | A photographed drawing surface (sheet, whiteboard) to draw on in image coordinates |
| `clip-letterbox.mp4` | Generated footage delivered with black bars (84 px top and bottom inside 720x1280) |
| `clip-plain.mp4` | Generated footage without bars |
